Restock server

Set up your server

Log in with the user name and password from the server's settings (RESTOCK_USER and RESTOCK_PASSWORD). If you didn't set a user name, it's admin.

Choose a passphrase

You'll sign in with this from now on, and the setup password stops working. Four or more random words works well, like kettle orbit lemon fence.

It never leaves this browser: the server only gets a key made from it. Keep it somewhere safe. If you lose it, you can reset it (see the server's README); your phones stay connected.

Use at least 20 characters, or four or more words.

Set up this server

Your server keeps your household: the phones sync through it, at home and away, and it keeps your price history. Phones still work on their own when it's off.

Everyone you add sees this name, like "This phone was added as Sarah's phone on Declan and Sarah".

The server can read what phones share with it (so it can merge it, keep history and run Home Assistant). Keep its data folder private, ideally on an encrypted disk.

All set

Your passphrase is set and the setup password no longer works.

Next, sign in with your passphrase, then open Server and phones and use Add a phone for each phone (they need Restock 0.9.4 or newer).

This server keeps a household from Restock 0.9.3. To move it onto the server, sign in, open Server and phones → Take this household, and scan the code with the household's owner phone (Restock 0.9.4 or newer). Until then everything works as before.
