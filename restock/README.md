# Restock server (Home Assistant app)

Your own server for a [Restock](https://github.com/d-plenty/Restock) household, running inside Home Assistant. Phones sync through it at home and away. It keeps your price history and spending (the Data tab), runs the shopping list with Home Assistant, and serves Restock in a browser and on iPhone. It's optional: phones work fully without it. See the Documentation tab for setup.
